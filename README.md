# YouTube Shorts Generator

AIで生成した画像と VOICEVOX の合成音声を組み合わせて、YouTube ショート動画（縦型 1080×1920）を自動生成するツールです。

---

## 必要なもの

| ソフト | 備考 |
|---|---|
| Windows 10 / 11 | Mac・Linux は非対応 |
| Python 3.10 以上 | 無料。セットアップ手順を参照 |
| VOICEVOX | 無料。ずんだもんなど多数のキャラクターボイスが使用可能 |

---

## セットアップ手順

### STEP 1 ── Python のインストール

1. `https://www.python.org/downloads/` を開く
2. 「Download Python」ボタンをクリック
3. ダウンロードしたインストーラーを実行
4. **「Add Python to PATH」に必ずチェックを入れる**
5. 「Install Now」をクリックしてインストール完了

### STEP 2 ── VOICEVOX のインストール

1. `https://voicevox.hiroshiba.jp/` を開く
2. 「ダウンロード」ボタンをクリック
3. OS: Windows / パッケージ: インストーラー を選択してダウンロード
4. インストーラーを実行してインストール完了

### STEP 3 ── このツールのセットアップ

1. 配布されたフォルダを任意の場所に展開（例：`C:\Tools\ShortsGenerator`）
2. フォルダ内の **「セットアップ.bat」** をダブルクリック
3. 自動でパッケージインストールとデスクトップショートカット作成が完了

## 使い方

### 起動

1. **VOICEVOX を先に起動**（タスクバーに常駐させる）
2. デスクトップの **「Shorts Generator」** をダブルクリック

### 動画の作成手順

#### 1. 使用画像を追加
- 左パネルの「＋ 追加」で画像ファイルを選択（PNG / JPG 対応）
- 複数枚選択可能（最大5枚推奨）
- ↑ ↓ ボタンで表示順を変更
- ✕ ボタンで削除

#### 2. ボイスを設定
- **キャラクター**: ずんだもん・めたんなど好きなキャラを選択
- **速度**: 読み上げの速さを調整（1.0 が標準）
- **ピッチ**: 声の高さを調整（0.0 が標準）
- **台本**: 動画で読み上げるテキストを入力
- 「▶ テスト再生」で確認、「■ 停止」で停止

#### 3. BGM を設定
- 「参照」ボタンで BGM ファイル（MP3 / WAV）を選択
- **BGM音量** と **ナレーション音量** をスライダーで調整
- 「▶ テスト再生」で確認

#### 4. 動画情報を入力
- **タイトル**: 動画下部に表示されるタイトル
- **説明文**: タイトルの下に表示されるテキスト

#### 5. 動画を生成
- 「💾 設定保存」で設定を保存
- 「🎬 動画生成」をクリック
- 進捗ウィンドウが表示され、完了後に通知

生成された動画は `output/video.mp4` に保存されます。

## フォルダ構成

```
ShortsGenerator/
├── app.py                  ← GUIアプリ本体
├── generate_video.py       ← 動画生成エンジン
├── config.json             ← 設定ファイル（GUIから自動更新）
├── requirements.txt        ← 必要パッケージ一覧
├── セットアップ.bat          ← 初回セットアップ用
├── input/
│   ├── images/             ← 使用する画像（GUIから自動コピー）
│   ├── narration.wav       ← 生成された音声（自動作成）
│   └── bgm.mp3             ← BGMファイル（自分で用意）
└── output/
    └── video.mp4           ← 生成された動画
```

## よくある質問

**Q. ボイスの一覧が「VOICEVOX未起動」と表示される**  
A. VOICEVOX を先に起動してから、アプリを再起動してください。

**Q. 動画生成に時間がかかる**  
A. 1分の動画で1〜2分程度かかります。生成中はほかの作業をしてお待ちください。

**Q. BGM がナレーションより大きい**  
A. アプリの「ナレーション音量」スライダーを右に、「BGM音量」スライダーを左に調整してください。

**Q. 画像が横長で上下が切れる**  
A. 縦型（9:16）の画像を使用すると最適です。横長画像は自動で中央クロップされます。
