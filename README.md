# YouTube Shorts Generator

AIで生成した画像と VOICEVOX の合成音声を組み合わせて、YouTube ショート動画（縦型 1080×1920）を自動生成するツールです。

---

## 必要なもの

| ソフト | 備考 |
|---|---|
| Windows 10 / 11 | Mac・Linux は非対応 |
| Python 3.10 以上 | 無料。セットアップ手順を参照 |
| VOICEVOX | 無料。ずんだもんなど多数のキャラクターボイスが使用可能 |

---

## セットアップ手順

### STEP 1 ── Python のインストール

1. `https://www.python.org/downloads/` を開く
2. 「Download Python」ボタンをクリック
3. ダウンロードしたインストーラーを実行
4. **「Add Python to PATH」に必ずチェックを入れる**
5. 「Install Now」をクリックしてインストール完了

### STEP 2 ── VOICEVOX のインストール

1. `https://voicevox.hiroshiba.jp/` を開く
2. 「ダウンロード」ボタンをクリック
3. OS: Windows / パッケージ: インストーラー を選択してダウンロード
4. インストーラーを実行してインストール完了

### STEP 3 ── このツールのセットアップ

1. このページ右上の「**Code**」→「**Download ZIP**」でダウンロード  
   （git が使える方は `git clone https://github.com/zatune-gif/shorts-video-generator.git` でも可）
2. ダウンロードした ZIP を任意の場所に展開（例：`C:\Tools\ShortsGenerator`）
3. フォルダ内の **「セットアップ.bat」** をダブルクリック
4. 自動でパッケージインストールとデスクトップショートカット作成が完了

## 使い方

### 起動

1. **VOICEVOX を先に起動**（タスクバーに常駐させる）
2. デスクトップの **「Shorts Generator」** をダブルクリック

### 動画の作成手順

#### ① 使用画像を追加
- 「＋ 追加」で画像ファイルを選択（PNG / JPG / WEBP 対応）
- 複数枚選択可能（最大20枚）
- ↑ ↓ ボタンで表示順を変更
- ✕ ボタンで削除

#### ② ボイスを設定
- **入力方式**：「VOICEVOX（合成音声）」または「録音ファイル」を選択
- VOICEVOX を選んだ場合：キャラクター・速度・ピッチ・台本を設定
- 録音ファイルを選んだ場合：「＋ 追加」で WAV ファイルを登録して選択
- 「▶ テスト再生」で確認、「■ 停止」で停止

**読み仮名の修正について**

漢字が正しく読まれない場合は、台本テキスト内に `{漢字|よみ}` の形式で読み仮名を指定できます。

```
例）{今日|きょう}は{晴れ|はれ}です
　　→ 「きょうははれです」と読み上げられます
```

波括弧 `{}` で囲み、`|`（縦棒）の左に表示用の漢字、右に読み仮名を書きます。  
テスト再生・動画生成ともに有効です。

#### ③ BGM を設定
- 「＋ 追加」で BGM ファイル（MP3 / WAV）を追加してライブラリに登録
- 使用したいファイルをクリックして選択（選択中のファイルが動画に使用されます）
- 「▶ 再生」でテスト再生可能

#### ④ 動画情報・音量を設定
- **タイトル**：動画下部に大きく表示されるタイトル
- **説明文**：タイトルの下に小さく表示される補足テキスト
- **BGM音量** と **ナレーション音量** をスライダーで調整
- **動画の保存先**：「参照」で出力先のファイルパスを変更可能

#### ⑤ 動画を生成
- 「💾 設定を保存」で設定を保存
- 「🎬 動画を生成する」をクリック
- 進捗ウィンドウが表示され、完了後に通知

生成された動画は指定した保存先（デフォルト：`output/video.mp4`）に保存されます。

## 設定の保存と読み込み

画面下部の「💾 設定を保存」「📂 設定を読み込む」ボタンを使うと、設定をファイルとして管理できます。

### 💾 設定を保存

保存されるもの：

| 項目 | 内容 |
|---|---|
| 使用画像 | ファイルパスと表示順 |
| ボイス設定 | キャラクター・速度・ピッチ・台本テキスト |
| BGM | 選択中の BGM ファイルパス |
| タイトル・説明文 | 動画に表示するテキスト |
| 音量バランス | BGM 音量・ナレーション音量 |
| 保存先 | 動画の出力先パス |

ダイアログで保存先とファイル名を自由に指定できます。  
**動画生成前に必ず保存してください**（「🎬 動画を生成する」を押すと自動で保存してから生成します）。

### 📂 設定を読み込む

保存済みの設定ファイルを選択すると、上記すべての設定が復元されます。  
読み込んだ後に内容を編集して、そのまま保存し直すこともできます。  
プロジェクトごとに設定ファイルを用意しておくと、素材だけ差し替えて別の動画をすばやく作成できます。

### 上書き保存と別名で保存

設定ファイルを読み込んだ状態で「💾 設定を保存」を押すと、保存方法を選ぶダイアログが表示されます。

| 選択肢 | 動作 |
|---|---|
| はい | 読み込んだファイルに上書き |
| いいえ | 別名で保存 |
| キャンセル | 保存せず戻る |

## フォルダ構成

```
ShortsGenerator/
├── app.py                  ← アプリ本体
├── generate_video.py       ← 動画生成エンジン
├── config.json             ← 設定ファイル（アプリから自動更新）
├── requirements.txt        ← 必要パッケージ一覧
├── セットアップ.bat          ← 初回セットアップ用
├── input/
│   ├── images/             ← 使用する画像（アプリから自動コピー）
│   ├── bgm/                ← BGMファイル（アプリから追加）
│   ├── narration/          ← 録音ファイル（録音モード時に追加）
│   └── narration.wav       ← 合成音声（VOICEVOX使用時に自動作成）
└── output/
    └── video.mp4           ← 生成された動画
```

## よくある質問

**Q. ボイスの一覧が「VOICEVOX未起動」と表示される**  
A. VOICEVOX を先に起動してから、アプリを再起動してください。

**Q. 動画生成に時間がかかる**  
A. 1分の動画で1〜2分程度かかります。生成中はほかの作業をしてお待ちください。

**Q. BGM がナレーションより大きい**  
A. アプリの「ナレーション音量」スライダーを右に、「BGM音量」スライダーを左に調整してください。

**Q. 画像が横長で上下が切れる**  
A. 縦型（9:16）の画像を使用すると最適です。横長画像は自動で中央クロップされます。
